# SVG Icons + Wikipedia Links Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace structural emoji in panel labels and kicker chips with Lucide SVG icons, and add a Romanian Wikipedia link to every person detail page that has a Wikidata QID.

**Architecture:** A new `templates/_icons.html.j2` partial holds an inline SVG sprite (29 Lucide symbols). It is included in `_detail-shell.html.j2` (covers all detail/index pages) and directly in `index.html.j2` (standalone page). Every `<span class="emo SIZE">EMOJI</span>` in a panel label or kicker div becomes `<svg class="icon SIZE" aria-hidden="true"><use href="#icon-NAME"/></svg>`. The Wikipedia link change is a 3-line template edit in `person-detail.html.j2`.

**Tech Stack:** Jinja2 templates, inline SVG (Lucide 0.468.0), Python 3 (one-off fetch script).

**Venv:** always activate `~/devbox/envs/240826/` before running Python commands.

## Task 1: Generate `templates/_icons.html.j2` via Lucide CDN

**Files:**
- Create: `tools/fetch_lucide_icons.py`

- [ ] **Step 1: Write fetch script**

Create `tools/fetch_lucide_icons.py` with this content:

```python
#!/usr/bin/env python3
"""Fetch Lucide icons and assemble templates/_icons.html.j2.
Run once from the project root: python3 tools/fetch_lucide_icons.py
"""
import re, urllib.request, pathlib

LUCIDE_VERSION = "0.468.0"
BASE = f"https://raw.githubusercontent.com/lucide-icons/lucide/{LUCIDE_VERSION}/icons"

ICONS = [
    "list-ordered", "users", "user", "pie-chart", "leaf", "flag",
    "graduation-cap", "hourglass", "globe", "star", "pencil-line",
    "swords", "file-text", "flask-conical", "terminal", "bar-chart-2",
    "tag", "trophy", "church", "calendar", "map-pin", "home",
    "map", "dna", "gem", "wheat", "scroll", "search", "building-2",
]

_STRIP = re.compile(
    r'\s+(?:stroke-width|stroke-linecap|stroke-linejoin|fill)="[^"]*"'
)

symbols = []
for name in ICONS:
    url = f"{BASE}/{name}.svg"
    print(f"  fetching {name}…", end=" ", flush=True)
    with urllib.request.urlopen(url) as r:
        svg = r.read().decode()
    # Extract inner content between outer <svg> tags
    inner = re.sub(r'<svg[^>]*>', '', svg).replace('</svg>', '').strip()
    # Strip layout attrs the .icon CSS will handle via inheritance;
    # keep stroke="currentColor" so colour inherits through shadow tree
    inner = _STRIP.sub('', inner)
    symbols.append(
        f'  <symbol id="icon-{name}" viewBox="0 0 24 24">\n'
        f'    {inner}\n'
        f'  </symbol>'
    )
    print("ok")

output = (
    '{# Auto-generated by tools/fetch_lucide_icons.py — do not edit manually #}\n'
    '<svg style="display:none" aria-hidden="true" focusable="false">\n'
    + '\n'.join(symbols)
    + '\n</svg>\n'
)
pathlib.Path("templates/_icons.html.j2").write_text(output)
print(f"\nWritten templates/_icons.html.j2 ({len(ICONS)} icons)")
```
